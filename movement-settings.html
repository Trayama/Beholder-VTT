官方 Move 设置

直接扩展 Owlbear 官方 Move 工具，不再注册独立移动入口。

官方 Move 墙体感知 开启后，CHARACTER / MOUNT Token 拖动由 Beholder 实时检测墙体；普通对象继续使用 Owlbear 原生拖动。关闭后官方 Move 完全恢复原生移动。
多选 Token 整组移动 选中多个对象后拖动其中一个，整组一起移动。任意角色 Token 遇到移动阻挡墙，整组都会停在最后安全位置。
碰撞对象：CHARACTER 与 MOUNT 图层。无需光源。墙体只读取「阻挡棋子移动」属性，不依赖视野或光照投影。
交互兼容说明 空白区域拖动使用 Beholder 框选；道具、地图和绘图沿用 Owlbear 默认拖动。旋转与缩放手柄临时交给 Owlbear 原生处理，结束后自动恢复墙体感知模式。
